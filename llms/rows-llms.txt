# Rows

> Rows is an AI-powered spreadsheet that connects to live data. Its public REST
> API (base https://api.rows.com/v1, Bearer API-key auth) lets you read
> workspaces/folders/spreadsheets and read-write table cells and values, plus a
> Vision endpoint that extracts structured data from files. Rows joined
> Superhuman in 2025.

## APIs
- [Rows API v1](https://developers.rows.com/): base https://api.rows.com/v1, Bearer API key
- [OpenAPI (derived)](openapi/rows-openapi.yml): 7 verified operations
